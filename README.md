# lissTrainer

> 反对在教室白板安装 LISS / Opposing the Installation of LISS on Classroom Whiteboards

English | [简体中文（暂无）](./README.zh-CN.md)

## 📖 About
lissTrainer is a documentation and advocacy repository that explains why installing LISS (Laboratory Information Management System) on daily classroom whiteboards is problematic. It argues that "compatibility" does not equal "suitability," and that a laboratory management platform should not invade an environment designed to protect classroom teaching.

The repository collects reasoning, real-world evidence, and scenario-based judgments to help schools, administrators, and teachers make informed decisions about whiteboard software deployment.

---

## 🎯 Core Arguments

- ✅ Compatibility ≠ Adaptation — LISS claims compatibility with all-in-one PCs and large-screen terminals, but its core design is to "receive server commands," not to serve real-time classroom interaction.

- ⚡ Performance Conflict — Class whiteboards already suffer from memory bottlenecks. A resident management client adds another background burden, causing lag, delays, and pop-ups during critical teaching moments.

- 🎯 Logic Misalignment — LISS's "laboratory management logic" (real-name login, behavior control, terminal statistics) does not match the whiteboard's "classroom teaching logic" (teacher-led, highly dynamic, zero interference).

- 🔒 Management Ethics & Lock-in — Once deployed in bulk, management software is hard to remove without passwords or special permissions, handing classroom continuity over to backend processes.

- 💎 Scenario-Based Judgment — Deploy only if the classroom is essentially a computer-lab extension with sufficient hardware (i5 + 8GB+). For regular classrooms, use lightweight, autonomously withdrawable tools instead.
